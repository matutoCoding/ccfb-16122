# 塔台选址与视认分析系统

面向支线机场新建/扩建塔台选址的网页版分析工具。TypeScript + 原生 WebGPU/WGSL 实现,
机场方案、塔台候选、天气预设与比选报告全部持久化在浏览器 IndexedDB,无需后端。

## 运行

```bash
npm install
npm run dev      # 开发服务器
npm test         # 核心算法单测(太阳天文/大气/视认/眩光, 59 项)
npm run build    # 类型检查 + 生产构建
```

需 Chrome/Edge 113+ 并启用硬件加速(WebGPU)。

## 关键技术

### 太阳天文(`src/core/solar.ts`)
NOAA Solar Position Algorithm 简化版:儒略日 → 儒略世纪 → 平黄经/近点角/中心差 →
视黄经/黄赤交角 → 赤纬/时差 → 时角 → 天顶角/高度角/方位角(北 0 顺),含 Bennett 大气折射修正。
测试用 NOAA 丹佛公开算例 + Meeus GMST 独立路径交叉验证,方位/高度误差 ≤ 0.2°。

### 大气散射(`src/render/`)
- 启动时 compute shader 预计算 256×64 透射率 LUT(太阳天顶角 × 海拔,Rayleigh+Mie 指数大气路径积分)
- 天空片元着色器对视线做 32 步单次散射数值积分(Bruneton 形式),Rayleigh 相位 + Henyey-Greenstein Mie 相位
- 含地球阴影判定、太阳盘与辉光、ACES 色调映射、线性→sRGB
- 场景网格按深度做 `T=exp(-σd)` 大气混合,雾色与消光系数由天气预设驱动,不是平铺白雾

### 视认分析(`src/core/visibility.ts`、`atmosphere.ts`、`glare.ts`)
- Koschmieder 定律:能见度 → 消光系数;Duntley 对比传输 + 张角相关分辨阈值
- 射线对建筑挤出体块求交,返回最近遮挡体用于反查
- 竖梃按均布圆周算角宽,外倾角计入水平有效投影
- 眩光:5 分钟步长扫描低太阳(≤30°)与跑道端/交叉口方位(±20°)重叠时段,竖梃挡太阳时剔除
